
# Mi Wallet

Aplicación web de billetera digital desarrollada como proyecto académico para el módulo Fundamentos del Desarrollo Front-end.

El proyecto permite simular operaciones básicas de una billetera digital, como iniciar sesión, consultar saldo, realizar depósitos y retiros, enviar dinero a contactos y consultar el historial de transacciones.
## Descripción
Alke Wallet es una aplicación Front-end diseñada para simular la administración de activos financieros de manera sencilla y dinámica.

La aplicación permite al usuario gestionar su saldo, realizar diferentes operaciones financieras simuladas y consultar sus movimientos.

Los datos son almacenados localmente mediante LocalStorage, permitiendo mantener el saldo, los contactos y el historial de movimientos durante la navegación.

## Funcionalidades

1. Inicio de sesión mediante credenciales.
2. Consulta del saldo disponible.
3. Realización de depósitos.
4. Realización de retiros.
5. Envío de dinero a contactos.
6. Registro de nuevos contactos.
7. Registro de contactos mediante RUT.
8. Búsqueda de contactos por nombre o alias.
9. Consulta del historial de movimientos.
10. Filtrado de movimientos por tipo.
11. Almacenamiento de datos mediante LocalStorage.
12. Diseño responsive.
13. Interfaz desarrollada utilizando Bootstrap.
14. Interactividad y manipulación del DOM mediante JavaScript y jQuery.
15. Navegación entre las diferentes pantallas de la aplicación.

## Tecnologías utilizadas

HTML5

Utilizado para crear la estructura y contenido de las diferentes pantallas de la aplicación.

CSS3

Utilizado para personalizar la interfaz y complementar el diseño visual.

JavaScript

Utilizado para implementar la lógica de la aplicación, validaciones, gestión del saldo, transferencias y movimientos.

jQuery

Utilizado para la manipulación del DOM, eventos e interacción con los elementos de la interfaz.

Bootstrap

Utilizado para crear componentes visuales y lograr un diseño responsive adaptable a diferentes tamaños de pantalla.

LocalStorage

Utilizado para almacenar localmente el saldo, contactos y movimientos realizados por el usuario.




## Para utilizar el proyecto:

Descargar o clonar el repositorio desde GitHub.
Abrir la carpeta del proyecto en Visual Studio Code.
Ingresar a la carpeta HTML.
Abrir el archivo index.html.
Seleccionar la opción "Iniciar sesión".
Ingresar las siguientes credenciales:
Correo: usuario@wallet.cl
Contraseña: 123456
Una vez iniciada la sesión, acceder al menú principal.
Desde el menú se pueden realizar depósitos, retiros, transferencias y consultar los movimientos.
Para realizar transferencias, se pueden seleccionar contactos existentes o agregar nuevos contactos mediante su RUT.
El saldo y los movimientos se almacenan localmente mediante LocalStorage.
